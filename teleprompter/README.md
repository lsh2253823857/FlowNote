# 顺词 · 安卓手机提词器

一个不需要后端的移动端 PWA 提词器。支持本地保存、TXT 导入、自动滚动、拖动正文或顶部时间轴调整进度、倒计时、竖屏/横屏、镜像、全屏、屏幕常亮和离线使用。

## 本地运行

在 `teleprompter` 目录启动静态服务器：

```powershell
npx serve .
```

也可以使用任意静态服务器。浏览器直接打开 `index.html` 可使用主要功能，但安装到桌面、离线缓存和屏幕常亮需要通过 `http://localhost` 或 HTTPS 访问。

## 安卓安装

1. 用 Chrome 打开部署后的 HTTPS 地址。
2. 点击页面右上角安装按钮，或浏览器菜单中的“添加到主屏幕”。
3. 安装后可从桌面全屏启动，首次成功打开后可离线使用。

开启“横屏提词”后，开始提词时会请求进入横屏全屏。若浏览器不允许自动锁定方向，请打开手机的“自动旋转”并横置手机，应用会自动切换到横屏专用布局。

## 测试

```powershell
node .\tests\core.test.mjs
node --check .\app.js
node --check .\sw.js
```

启动本地服务器后，可以用本机 Chrome 做安卓视口、提词播放和离线重载冒烟测试：

```powershell
node .\tests\mobile-smoke.mjs
```

## 当前边界

仓库中的 `../android-app` 已提供原生 Android 包装工程，支持生成可离线安装的 APK。当前版本仍不具备“悬浮在其他相机 App 上方”的系统权限；如果需要跨应用悬浮提词，需要再接入安卓悬浮窗服务。

# Wait Step Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Allow a stopped recording to insert a configurable fixed-duration wait between two recorded steps on the current route.

**Architecture:** Add a validated `wait` action with an integer `seconds` value. The popup inserts it after a selected step through a popup-only background command; the background assigns a globally unique step ID and preserves existing branch anchors. The converter carries the wait into `workflow.json`, and generated Skill instructions require waiting before continuing to the next action.

**Tech Stack:** Chrome Extension Manifest V3, JavaScript, HTML/CSS, Python 3 standard library, Node.js/Playwright smoke tests.
